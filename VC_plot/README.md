# VC_plot — анализ C(V) и 1/C^2

Краткое описание
- Скрипт `plot_c_vs_v.py` обрабатывает файлы `CNc.txt` в поддиректориях указанной папки и строит графики:
  - C(V) (ёмкость в пФ),
  - 1/C^2 (единица в 1 / нФ^2),
  - первая производная d(1/C^2)/dV с сглаживанием и фиттом убывающей сигмоиды,
  - анализ линейных участков и точка пересечения прямых.
- Для каждого обработанного набора данных создаётся папка `results` рядом с корнем данных.

Входные данные
- Скрипт ожидает файлы с именем `CNc.txt`.
- Формат: текстовый файл, строки с метаданными начинаются с `*`. Числовые строки содержат по крайней мере два столбца: напряжение (V) и ёмкость.
- Важное: ёмкость должна быть в пФ (пикофарадах). Имя столбца в итоговой DataFrame — `Capacitance_pF`.

Выходные файлы (в папке results/…)
- 1_<detector>_<freq>_VC.png — график C(V) (пФ).
- 2_<detector>_<freq>_VC2.png — график 1/C^2 (1 / нФ^2).
- 3_<detector>_<freq>_D1C2.png — график первой производной и сглаживания; если фит удачен — отображение сигмоиды.
- <detector>_<freq>_VC_table.csv — таблица с колонками:
  - Voltage_V, Capacitance_pF, InvC2_1_per_nF2, D1InvC2, SmoothedD1InvC2, Sigmoid_A, Sigmoid_x0, Sigmoid_k, Sigmoid_y0
- 4_<detector>_<freq>_analysys.png — финальный комбинированный график (C и 1/C^2 с линиями регрессии).
- <detector>_<freq>_analysys.txt — текстовый файл с результатами анализа (зоны, параметры прямых, точка пересечения и т.д.).

Краткая справка по алгоритму
- Строится InvC2 = 1/(C_nF^2) по положительным значениям C.
- Вычисляется первая производная по V: d(1/C^2)/dV.
- Первая производная сглаживается фильтром Савицкого-Голея.
- Проводится один фит убывающей логистической сигмоиды к сглаженной первой производной (если достаточно точек).
- Оценивается переходная зона вокруг центра сигмоиды (ширина ~ 1/k).
- Выполняется локальная линейная регрессия по левому и правому линейным участкам (вне переходной зоны) и находится их пересечение.
