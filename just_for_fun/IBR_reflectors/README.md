### IBR_reflectors

Краткое описание
- Набор скриптов для моделирования перекрытия активной зоны (АЗ) вращающимися сегментированными дисками (ОПО и ДПО).
- Скрипт рассчитывает заэкраненную часть АЗ во времени, строит и сохраняет графики, а также вычисляет некоторые метрики (например, FWHM для нормализованной экспоненты).

Файл скрипта
- Основной скрипт: `IBR_reflectors/IBR_reflectors.py`
- Скрипт генерирует и сохраняет PNG-графики в текущей директории.

Ключевые параметры (в начале скрипта)
- AZ_deg — ширина окна (АЗ) в градусах.
- N, M — числа сегментов на двух дисках.
- F, f — частоты вращения дисков (в Гц).
- t_max — длительность моделирования.
- n_points — число временных точек.
- EXP_FACTOR — множитель в экспоненциальной обработке.
- FILTER_SIGMA_SEC — ширина гауссова фильтра в секундах.

Интерпретация результатов
- blocked_deg: количество экранированных градусов внутри окна AZ_deg.
- norm_blocked_deg: процент экранированной части окна.
- exp-метрика: exp(blocked/AZ * EXP_FACTOR) — используется для усиления отличий.
- Фильтрация сглаживает сигнал перед поиском параметров вроде FWHM.
- FWHM рассчитывается как первая после нуля точка пересечения фильтрованной кривой с уровнем 0.5, результат выводится в микросекундах (мкс). Если пересечение не найдено, выводится соответствующее сообщение.
