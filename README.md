# Летняя практика в ОИЯИ 2025

Репозиторий для проектов, результатов измерений и материалов летней практики в секторе №2 (создание измерительных систем на основе полупроводниковых детекторов) Научно-экспериментального отдела барионной материи на Нуклотроне Лаборатории физики высоких энергий имени В.И.Векслера и А.М.Балдина Объединённого института ядерных исследований (сектор №2 НЭОБМН ЛФВЭ ОИЯИ).

Кратко: набор аналитических и вспомогательных скриптов для анализа спектров, моделирования пиков Брэгга, обработки C(V)/I(V) измерений и вспомогательных утилит.

## Структура репозитория (корневые папки)
- alpha_spectrum — анализ альфа-спектров: подгонка пиков, пакетная обработка, сбор результатов и визуализация.
- bragg_peak — расчёт потерь энергии α-частиц по таблице ASTAR, моделирование пика Брэгга и сравнение с экспериментом.
- data - результаты всех измерений и их обработки.
- final_report - отчёт и вспомогательные файлы (схемы, задание на практику и отзыв).
- just_for_fun/IBR_reflectors — моделирование экранирования активной зоны ИБР-2 вращающимися отражателями.
- photo - фотографии детекторов (в том числе с использованием установки NORGAU NVMII-5040D).
- VC_plot — анализ C(V) и 1/C^2, вычисление d(1/C^2)/dV, фит сигмоиды и локальная регрессия.
- VI_plot — построение ВАХ (I-V) из .xlsx, коррекция по температуре и сохранение графиков.
