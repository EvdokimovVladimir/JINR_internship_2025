# VI_plot

Краткий скрипт для загрузки и построения ВАХ (I-V) из .xlsx файлов.

Назначение
- Считывает таблицы из .xlsx файлов в папке.
- Строит графики VSource vs Readings и опционально VSource vs Readings, приведённых к 20°C.
- Поддерживает сохранение графиков в папку `results`.

Структура проекта (важные файлы)
- VI_plot.py — основной скрипт (подробности ниже).
- Ожидается, что входные .xlsx файлы лежат в папке (по умолчанию `./data`).

Формат входных xlsx
- На листе первая строка должна содержать заголовки в первых трёх колонках:
  - A1 = "Readings"
  - B1 = "Timestamp"
  - C1 = "VSource"
- D1 — (опционально) значение температуры в °C (может быть строкой с запятой).
- D2 — (опционально) название детектора.
- Значения данных начинаются со 2-й строки; чтение продолжается до первой полностью пустой строки в первых трёх колонках.

Запуск (пример)
- По умолчанию:
  - python VI_plot.py --folder data
- Параметры:
  - --folder, -f  : путь к папке с .xlsx (по умолчанию `data`)
  - --no-plot     : не показывать интерактивные окна с графиками
  - --out         : сохранить графики в папку `./results`
  - --log         : дополнительно построить графики с логарифмической осью Oy
  - --t0          : построить графики для токов, приведённых к 20°C (T0 = 293 K)

Коррекция по температуре
- Токи могут быть приведены к T0 = 293 K (20°C) по формуле:
  I0 = I / ( (T/T0)^2 * exp( (Eg/(2k)) * (T-T0)/(T0*T) ) )
  где Eg ≈ 1.17 eV, k — постоянная Больцмана в эВ/K (8.617333262e-5 eV/K).
- Если D1 пусто или некорректно, коррекция не применяется для соответствующего листа.

Выбор единиц тока
- Скрипт автоматически выбирает удобную единицу: A, мА, мкА, нА, пА по максимальному абсолютному значению тока.

Выходные данные
- В консоль выводится краткая сводка по каждому листу (имя файла, лист, детектор, температура и число строк).
- При указании `--out` сохраняются PNG-файлы в `./results`: 
  - `VI_curves.png` (и при `--log` — `VI_curves_log.png`)
  - `VI_curves_T0.png` (и при `--log` — `VI_curves_T0_log.png`)
